# Strict terminal generations and authoritative diagnosis stages

Normal and no-action terminal payloads now distinguish current summary-bearing records from legacy records, while diagnosis projection preserves authoritative non-`NOT_RUN` stages. The MCP report gate returns a fixed public failure for rendering errors and permits same-key report retry without rerunning orchestration. One compatibility hole remains: a valid pre-change nested review shape is accepted but normalized during serialization. Watch for: **confirmed** pre-change normal outcomes gain `review.no_action_required=false` when replayed, violating the exact legacy-generation contract.

**Verdict**: NEEDS_CHANGES

## High-level view

Exact outer field sets and the nested analysis-summary field discriminate current, legacy, normal, and no-action records. Current summaries must be non-null objects; no-action summaries are also bound to a clean five-stage result.

Only unresolved diagnosis stages are projected from a verified diagnose node. Authoritative failed, skipped, unavailable, reused, or succeeded stages survive through Host and report projection.

**confirmed** — The legacy discriminator does not retain the older nested review shape. `_reconstruct_result` accepts the pre-change four-field review object, but `HostDecisionOutcome` emits the new fifth field on replay.

## Pre-change normal outcomes do not replay with their exact field shape

**confirmed** — `src/riskprobe/host_decision.py:216-228` strips the three new analysis-summary fields when serializing a legacy normal outcome, but it does not restore the pre-change nested review field set. `src/riskprobe/agents/results.py:235-248` accepts a review without `no_action_required` and defaults it to `false`; reconstruction loses the raw generation marker, so `model_dump(mode="json")` adds `no_action_required: false`.

A base-revision normal outcome is therefore accepted by `_outcome_from_payload`, but its replay differs from the input. The regression at `tests/test_host_decision.py:1069` derives its “legacy” payload from a current result and removes only analysis-summary fields, leaving the new review member in place. Add a true pre-change fixture with four review fields, preserve exact serialization through a dedicated legacy variant or retained generation flag, and reject impossible current-summary/legacy-review hybrids.

This breaks durable idempotent replay for persisted normal sessions and leaves the decoder accepting a mixed generation that no encoder emits.
