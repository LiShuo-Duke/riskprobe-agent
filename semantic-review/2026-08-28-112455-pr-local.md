# Terminal summary generation and diagnosis-stage authority

Task A tightens Host generation checks, preserves legacy replay shapes, and projects executed diagnosis stages without overwriting authoritative non-`NOT_RUN` states. Report publication failures remain fixed-code, non-leaking, and retryable with the same key. One generation gap remains: a new current normal outcome with null summaries is serialized and accepted as legacy. Watch for: **confirmed** — summary absence can downgrade current state into the legacy decoder instead of failing closed.

**Verdict**: NEEDS_CHANGES

## High-level view

Current payloads use three markers: top-level summaries, nested `AgentResult.analysis_summary`, and the exact review field set. Legacy normal payloads intentionally accept both historical review shapes. `HostDecisionOutcome.serialize_generation`, however, removes all current markers based on `None` values rather than proven legacy origin.

Diagnosis projection resolves only `NOT_RUN` stages. `row_count >= 2` is sufficient in the fixed local path because `_reference_current_frames` always falls back to a non-empty row split; Host does not rewrite diagnosis stages, and no-action reports consume `TerminalReportSubject.analysis_summary` directly.

Publication exceptions map to `agent_orchestration_failed`; same-key retries reuse the terminal decision and retry only publication. Provider, evidence, review, idempotency, expiry, privacy, and finalized-run gates were not relaxed in the inspected Task A delta.

### Summary-less current normal outcomes are silently downgraded to legacy

**Confirmed:** `HostDecisionOutcome` permits `analysis_summary=None` and `decision_summary=None`. Its serializer removes both fields and nested `AgentResult.analysis_summary` whenever all three are absent (`src/riskprobe/host_decision.py:222-237`), even for a newly constructed current object. That payload matches `_LEGACY_NORMAL_OUTCOME_FIELDS`; the legacy decoder intentionally accepts a current review shape when nested `analysis_summary` is absent (`src/riskprobe/host_decision.py:1540-1546`), so the object reloads as valid legacy state.

This bypasses the null/mixed-generation fail-closed requirement. Track legacy origin explicitly with a dedicated legacy normal model or a private flag set only by the legacy decoder, and strip fields only for that origin. Add a regression test proving a fresh summary-less normal outcome cannot serialize/persist/reload as legacy while both historical legacy review shapes still round-trip exactly.
